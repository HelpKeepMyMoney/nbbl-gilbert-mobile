# NBBL Gilbert Mobile

Mobile landing page for **NBBL Gilbert** — the first physical home of [No Backboard Basketball](https://github.com/HelpKeepMyMoney/nbbl-gilbert-mobile) in Gilbert, Arizona.

Opening September 1, 2026.

## Overview

A single-page marketing site designed for mobile-first viewing. It promotes team training, showcases, performance measurement, audience building, fundraising, and creator access at the NBBL Gilbert facility.

**Live site:** [nbbl-gilbert-mobile.vercel.app](https://nbbl-gilbert-mobile.vercel.app)

## Tech Stack

- HTML5, CSS3, vanilla JavaScript
- No build tools or dependencies
- Google Fonts (Barlow Condensed, Inter)
- Static assets in `assets/`

## Project Structure

```
nbbl_gilbert_demo/
├── index.html      # Full page — markup, styles, and scripts
├── assets/         # Images (WebP and JPEG)
└── README.md
```

## Getting Started

Open `index.html` in a browser, or serve the folder with any static file server:

```bash
# Python
python -m http.server 8000

# Node (npx)
npx serve .
```

Then visit `http://localhost:8000`.

## Deployment

This project is a static site and can be deployed to any static host:

- [Vercel](https://vercel.com)
- [Netlify](https://netlify.com)
- [GitHub Pages](https://pages.github.com)

No build step is required — deploy the project root as-is.
